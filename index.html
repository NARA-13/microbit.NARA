Dokumentasi micro:bit

Langkah singkat

Flash program Bluetooth UART ke micro:bit (MakeCode → extension Bluetooth → bluetooth startUartService).

Buat model image classification di teachablemachine.withgoogle.com, export → Upload (Cloud) → salin URL-nya, lalu klik Load AI Model.

Klik Connect Micro:Bit, pilih AI Mode, arahkan kamera ke gesture/objek — robot bergerak sesuai class.

Agar browser bisa terhubung tanpa pairing: di MakeCode buka Project Settings → No Pairing Required sebelum flash. Web Bluetooth hanya tersedia di Chrome/Edge (desktop & Android) via HTTPS, bukan di iOS Safari.

Protokol UART

        
Papan mengirim data dengan format kunci:nilai per baris. Contoh yang dikenali:

        

          suhu:28.5kelembaban:65
          cahaya:120suara:44
          kompas:180x:512
          lamp:onfan:2
          mode:auto
        

        
Kunci lain otomatis dibuatkan kartu baru. Perintah keluar: up, down, left, right, stop, horn, a, b, c<0-180>, x<0-180>, lamp:on/off/<0-100>, fan:on/off/<0-3>, mode:manual/auto.
